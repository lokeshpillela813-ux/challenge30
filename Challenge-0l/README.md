#Challenge01-students Marks Calculator
##problem statement
Write a C program to calculate the student marks.
##Algorithm
1.start
2.Read the marks of five subjects:m1,m2,m3,m4,m5.
3.Calculate the total marks:total=m1+m2+m3+m4+m5
4.Calculate the average marks:average=total/5.0
5.Calculate the percentage:percecentage=(total/500.0)*100
6.Display the total,average and percentage.
7.stop
